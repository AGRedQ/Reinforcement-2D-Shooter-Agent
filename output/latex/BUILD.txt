Reproduce the adaptive matched experiment (from the repository root):
  python training_bilstm_scratch.py --model paper_bilstm_seed0 --device cuda \
    --run-dir reports/paper_bilstm_seed0 --min-steps 2501688 \
    --train-control --no-dashboard

A fresh run can stop at a different budget under this mastery-based protocol.
For a fixed-budget comparison, train both architectures independently:
  python training_bilstm_scratch.py --architecture feedforward \
    --model paper_ff_seed0 --device cuda --seed 0 --steps 2769992 \
    --no-until-curriculum-complete --no-dashboard --skip-evaluation \
    --run-dir reports/paper_ff_seed0
  python training_bilstm_scratch.py --architecture bilstm \
    --model paper_bi_seed0 --device cuda --seed 0 --steps 2769992 \
    --no-until-curriculum-complete --no-dashboard --skip-evaluation \
    --run-dir reports/paper_bi_seed0
Repeat with additional independent training seeds before generalizing.

Evaluate the supplied primary candidate and matched control:
  python training_bilstm_scratch.py --evaluate-only --device cpu \
    --model bilstm_gpu_all_stages_20261112 \
    --compare-to checkpoints/bilstm_gpu_all_stages_20261112_feedforward_control.pt \
    --run-dir reports/paper_matched_reevaluation --no-dashboard
The default maps 14-17, spawn seeds 20000-20005, and stages 0-4 match the paper.
Use --model paper_bi_seed0 and --compare-to checkpoints/paper_ff_seed0.pt
with a fresh run directory to compare the fixed-budget replications instead.
